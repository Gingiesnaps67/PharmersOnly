# PharmersOnly

A database of medication and everything you need to know with safety and patient teaching.

## Open the app
**https://gingiesnaps67.github.io/PharmersOnly/** — works in Safari or Chrome on iPhone, Android, or a computer. No install needed.

Tip (iPhone): in Safari tap **Share → Add to Home Screen** to open it like an app.

## Download it
Download [`pharm-master.html`](pharm-master.html) (tap the file, then the download ↓ button) and open it in a browser on a computer. iPhones can't run a downloaded HTML file — use the link above on a phone.

## Notes
- Progress saves in your own browser on your own device. Nobody else can see it.
- For education only — not for real-time medication administration decisions. Always follow the actual order, facility policy, and a current drug reference.
